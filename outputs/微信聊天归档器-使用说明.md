# 微信聊天归档器 1.2.0

## 功能

- 监听授权后的微信通知。
- 导入 Moect 导出的未加密 ZIP，包括个人聊天和群聊历史。
- 保存图片、视频、语音、文档、GIF/WebP 动画表情及其他文件。
- 支持从手机多选导入媒体和文件，并在应用内预览图片、动图、视频、音频和文本。
- 消息和附件存入 Android 应用私有目录，支持搜索、预览、打开和删除。
- 生成包含附件清单的 Markdown，可通过系统保存或分享。

## 安装

1. 将 `微信聊天归档器-v1.2.0.apk` 复制到 Android 手机。
2. 点击 APK，并允许文件管理器安装未知应用。
3. 最低支持 Android 8.0（API 26）。
4. 实时采集需要开启“通知访问”；不开启时仍可导入历史。

## 导入本机媒体

1. 在首页点击“导入本地媒体”。
2. 在系统文件选择器中一次选择多张图片、视频、GIF/WebP 表情或任意文档。
3. 应用会把所选文件复制到私有目录，并在列表顶部生成一条“本地媒体库”记录。
4. 点击该记录查看附件卡片；图片、动图、视频、音频和文本文件可在应用内预览，其他文件可交给系统查看器打开。

微信通知只包含可见文字及少数应用附带的图片，不包含聊天视频、文件和多数表情包的原文件，因此这些内容必须通过本机多选导入或 Moect ZIP 获取。
## 导入历史

Android 无法直接读取微信私有数据库。完整历史需在 Windows 上使用
[Moect](https://github.com/mofan6/Moect) 导出：

1. 登录 Windows 微信并启动 Moect。
2. 选择个人或群聊，导出 JSON。
3. 保留图片、动画表情、视频、语音和文件，不要使用快速导出或跳过附件。
4. 将 JSON 及 `*_assets` 目录打进同一个未加密 ZIP。
5. 在 Android 应用内点击“导入 Moect ZIP”并选择该文件。

支持子目录结构，例如：

```text
会话A/chat.json
会话A/chat_assets/resources/image/photo.jpg
```

加密 ZIP 暂不支持。单附件最大 2 GB，单次归档附件总量最大 20 GB。

## 数据边界

- 应用不读取或解密微信数据库。
- 只归档通知中可见的文字，以及 Moect 已成功导出的资源。
- 静音会话、合并通知中的隐藏内容、过期的远端媒体、仍加密或缺失的附件无法恢复。
- 微信专有且无法解码的表情只能保存原文件或标记为不支持。
- 删除消息会删除其附件文件；清空和卸载应用也会删除应用私有数据，请先导出需要的记录。
- 系统云备份和设备迁移已关闭。

## 验证

- 单元测试覆盖通知与 Moect JSON 解析、附件类型、路径安全、去重和 Markdown。
- Android 仪器测试覆盖 MessagingStyle 兼容解析、通知图片落盘、本机多文件导入、SQLite 单例复用、v1→v2 迁移、ZIP 导入、重复导入、附件存储、只读 Provider 和级联删除。
- API 37 模拟器已跑通 ZIP 导入、多模态列表、附件详情和图片预览。
- Release APK 使用本机 Debug 证书签名，仅供个人安装，不适用于应用商店发布。
