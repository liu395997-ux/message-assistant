# 微信通知归档器

一个只在 Android 手机上运行的微信通知归档工具。它使用 Android 官方
`NotificationListenerService`，归档你自己手机中实际出现的微信通知文字，并可在应用内生成、
保存和分享 Markdown 文档。

## 功能

- 只接收包名为 `com.tencent.mm` 的微信通知。
- 支持联系人私聊、群聊和 Android MessagingStyle 通知。
- 支持关闭采集以及按会话名称白名单过滤。
- 使用本机 SQLite 保存记录，相同通知不会重复入库。
- 支持会话、发送者和正文搜索，支持单条删除和全部清空。
- 可生成 UTF-8 `.md` 文件，通过系统文件选择器保存到下载目录或其他位置。
- 可通过系统分享面板把 Markdown 文件发送给其他应用。
- 不需要电脑、服务器、网络权限或云端账号。

## 安装

1. 将 `微信通知归档器-v1.0.0.apk` 复制到 Android 手机。
2. 在文件管理器中点击 APK，允许该文件管理器“安装未知应用”。
3. 安装并打开“微信通知归档器”。
4. 点击“打开通知访问设置”，在系统列表中找到“微信通知归档器”并开启通知访问。
5. 返回应用，状态应显示“通知访问已开启”。
6. 可点击“采集设置”关闭采集或填写会话白名单。

应用最低支持 Android 8.0（API 26）。

## 使用

- 微信收到新通知后，应用会把通知中可见的标题、摘要、会话和发送者写入本地数据库。
- 点击任意消息可查看全文、复制文本或删除该条记录。
- “保存 Markdown”会打开系统文件选择器，并写入完整的归档。
- “分享 Markdown”会打开系统分享面板，并分享一个真实的 `.md` 文件。
- 搜索只影响当前显示列表，Markdown 导出始终包含全部记录。
- “清空”会删除手机上的全部归档，删除后无法恢复。

## 数据边界

本应用不读取微信数据库，不修改微信客户端，不自动回复，也不尝试绕过微信登录或加密。

因此以下内容可能无法归档：

- 安装和授权前的历史聊天；
- 被设置为免打扰或关闭通知的会话；
- 只显示“N 条新消息”的合并通知中的具体内容；
- 图片、文件、语音和视频的实际内容；
- 微信没有放入系统通知中的任何信息。

历史记录仍应使用微信自带的“聊天记录迁移与备份”保存。通知中包含其他人的私人信息，请仅在
获得合理授权的前提下使用，并妥善保护导出的 Markdown 文件。

## 技术结构

```text
微信通知
  -> WeChatNotificationListener
  -> 包名与会话白名单过滤
  -> 通知字段解析与去重指纹
  -> SQLite（应用私有目录）
  -> Android 原生界面
  -> MarkdownExporter
  -> 系统文件保存 / 只读内容提供器分享
```

关键代码：

- `service/WeChatNotificationListener.java`：系统通知监听与字段提取。
- `domain/NotificationParser.java`：普通、分组和 MessagingStyle 通知解析。
- `domain/CapturePolicy.java`：微信包名与白名单策略。
- `domain/MarkdownExporter.java`：Markdown 生成和危险字符处理。
- `data/ArchiveDatabase.java`：SQLite 持久化、查询、去重和删除。
- `export/MarkdownShareProvider.java`：只读、临时授权的 Markdown 文件分享。

## 构建与测试

```powershell
.\verify.ps1
.\verify.ps1 -Release
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease
```

项目路径包含中文时，Windows 上 AGP 的 JVM 测试执行器可能出现测试类路径编码问题。
`verify.ps1` 会临时把项目映射到一个空闲的 ASCII 盘符来运行测试，结束后自动解除映射，
不会移动或修改项目文件。

测试覆盖通知解析、采集策略、白名单、去重指纹、Markdown 内容与文件名生成，共 22 个
JVM 单元测试。

本次交付的 release APK 使用本机 Android debug 签名证书完成个人安装签名。该 APK 可正常安装，
但不可用于应用商店发布。若以后更换签名，请先导出已有记录，再卸载旧版本安装新版本。
